Mathematical Grounding: Cross-Attention Fusion

$$\mathbf{Z}_{fused} = \text{LayerNorm}(\mathbf{H}_{vision} + \text{MultiHeadAttn}(Q = \mathbf{H}_{text}\mathbf{W}_Q, K = \mathbf{H}_{vis}\mathbf{W}_K, V = \mathbf{H}_{vis}\mathbf{W}_V))$$

When patient text mentions focal symptoms (e.g. "right hemithorax pleuritic pain"), the queries attend selectively to feature patches in the corresponding anatomical quadrant, boosting spatial sensitivity even on subtle, sub-radiological opacities.

Calibration Formula: Platt Scaling & ECE

$$\hat{p}_i = \sigma\left(\frac{z_i}{T}\right), \quad \text{ECE} = \sum_{m=1}^M \frac{|B_m|}{N} \big|\text{acc}(B_m) - \text{conf}(B_m)\big|$$

Strict Clinical Guardrails & Zero-Hallucination Framework

Medical AI cannot operate like generic chatbots. Review our rigorous safety checks and verification tests.

MANDATORY GUARDRAIL 1

Zero Hallucinations (Evidence-Based Only)

In standard chat models, the AI might fabricate a diagnosis without proof. Under PULSE-CV, every claim must have a receipt.

Visual Receipt: Precise bounding box coordinates or CAM activation map (x, y, radius) required for every anatomical finding.
Textual Receipt: Verbatim sentence quote from clinical notes with character start/end index.
Rejection Filter: If a candidate finding cannot be cross-referenced to either modality, it is automatically discarded as hallucination.
MANDATORY GUARDRAIL 2

Calibrated Confidence & Uncertainty Quantification

A model that claims 99% confidence on an overexposed, motion-blurred scan is dangerous. The system assesses scan quality and conveys uncertainty.

Image Quality Assessment (IQA): Blurriness, contrast, rotation, and clipping are graded before inference.
Monte Carlo Dropout / Ensemble Variance: Epistemic uncertainty measured across 10 forward passes.
Degraded Scan Downgrade: Artificially noisy images automatically reduce maximum confidence and trigger physician review.
MANDATORY GUARDRAIL 3

Role Enforcement (Physician Co-Pilot, Not Replacement)

The AI never issues final diagnostic verdicts like "The patient has COVID-19." It adopts collegial, collaborative clinical phrasing.

Language Linter: Rejects deterministic claims ("Patient suffers from...") in favor of "Consider evaluating right base for...".
Actionable Next Steps: Recommends confirmatory imaging (CT thorax), lab panels (procalcitonin), or clinical follow-ups.
FDA SaMD Compliance Guard: Complies with Software as a Medical Device Clinical Decision Support guidance (21 U.S.C. 360j(o)(1)(E)).

PyTorch Hackathon Implementation Blueprint (`multimodal_fusion.py`) 
import torch
import torch.nn as nn
from transformers import AutoModel
from torchvision.models import densenet121

class MultimodalMedicalIntelligence(nn.Module):
    def __init__(self, num_classes=14, embed_dim=512):
        super().__init__()
        # Phase 1: Vision Encoder (Extract spatial feature grid)
        vision_base = densenet121(weights="DEFAULT")
        self.vision_encoder = vision_base.features  # Output shape: [B, 1024, H/32, W/32]
        self.vis_proj = nn.Conv2d(1024, embed_dim, kernel_size=1)
        
        # Phase 2: Text Encoder (ClinicalBERT)
        self.text_encoder = AutoModel.from_pretrained("emilyalsentzer/Bio_ClinicalBERT")
        self.txt_proj = nn.Linear(self.text_encoder.config.hidden_size, embed_dim)
        
        # Cross-Attention Multimodal Fusion (The Brain)
        self.cross_attention = nn.MultiheadAttention(embed_dim=embed_dim, num_heads=8, batch_first=True)
        
        # Calibrated Classifier & Temperature Scaling
        self.classifier = nn.Linear(embed_dim, num_classes)
        self.temperature = nn.Parameter(torch.ones(1) * 1.5)

    def forward(self, images, text_input_ids, text_attn_mask):
        # 1. Vision Features (spatial tokens)
        vis_feat = self.vis_proj(self.vision_encoder(images)) # [B, embed_dim, 16, 16]
        B, C, H, W = vis_feat.shape
        vis_tokens = vis_feat.flatten(2).permute(0, 2, 1)    # [B, 256, embed_dim]
        
        # 2. Text Features
        text_out = self.text_encoder(input_ids=text_input_ids, attention_mask=text_attn_mask)
        txt_tokens = self.txt_proj(text_out.last_hidden_state)  # [B, SeqLen, embed_dim]
        
        # 3. Cross-Modal Fusion (Text attends to Visual Features)
        fused_tokens, attn_weights = self.cross_attention(
            query=txt_tokens, key=vis_tokens, value=vis_tokens
        )
        
        # 4. Calibrated Prediction & Evidence Receipts
        pooled = fused_tokens.mean(dim=1)
        logits = self.classifier(pooled)
        calibrated_probs = torch.sigmoid(logits / self.temperature)
        
        return calibrated_probs, attn_weights
